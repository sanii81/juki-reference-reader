# 住基事務処理要領 参照リーダー

住民基本台帳事務処理要領の全９章を読み、項番・住基法・委任省令を右側パネルで参照する静的HTMLです。

## 開き方

このリポジトリをダウンロード・展開し、`index.html` をブラウザで開いてください。インストールやサーバーは不要です。`assets/001094645.pdf` は原本確認リンクに必要なので、フォルダ構成を保ってください。

本文の参照リンクを押すと右側に参照先を表示します。「総務省令」から対応条文を開けます。複数の委任先がある場合は一覧から選びます。「戻る」でパネルの履歴とスクロール位置に戻り、左側の本文位置は保持します。右側の条文上でトラックパッドの２本指操作によりスクロールできます。

## 収録資料

- 住民基本台帳事務処理要領：**2026年10月8日に確認した、令和8年6月14日施行の版**（001094645.pdf、101ページ）。[総務省の掲載ページ](https://www.soumu.go.jp/main_sosiki/jichi_gyousei/daityo/gaiyou.html)／[原本PDF](https://www.soumu.go.jp/main_content/001094645.pdf)
- 住民基本台帳法
- 住民基本台帳法施行規則
- 住民票等の閲覧・写し交付省令
- 戸籍の附票等の写し交付省令
- 準法定事務・処理者に関する省令
- 戸籍事項の通知方法を定める命令

法令データはe-Gov法令APIから取得した**2026年10月８日時点**の保存版で、HTML内に埋め込んでいます。各法令パネルに出典リンクと収録版の施行日を表示します。現行最新版を保証するものではありません。要領の改訂時点と保存法令の適用時点が一致することは未確認です。

要領本文はPDF抽出時の行折りを結合して表示しています。字面は原本PDFで確認してください。重複する項番は複数箇所を表示し、未解決の参照先２件は別項番で代用せず明示しています。

## 参照リンクについて・指摘のお願い

地方自治法など、現在は参照リンクを付けていない法令があります。

また、事務処理要領内の参照先や、法令の条文へのリンクに誤りがありましたら、[Issue](https://github.com/sanii81/juki-reference-reader/issues)でお知らせください。リンクが付いていない箇所への追加のご提案も歓迎します。

該当する項目番号、リンクの文言、正しいと思われる参照先を、分かる範囲で記載いただけると助かります。修正のPull Requestも歓迎します。

## 検証

Node.jsがある環境で `node verify.cjs` を実行すると、全９章の参照解決、省令リンク、パネル履歴、スクロール処理を検証します。これはコード検証であり、実ブラウザや実機のトラックパッドを操作するテストではありません。
